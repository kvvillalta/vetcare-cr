
# 🐾 VetCare CR - Clínica Veterinaria

## Descripción del proyecto

VetCare CR es un sitio web diseñado para una clínica veterinaria, creado con el objetivo de brindar información sobre servicios de atención y cuidado integral para mascotas.

El proyecto presenta una interfaz moderna, limpia y adaptable, enfocada en ofrecer una experiencia agradable para los usuarios que buscan servicios veterinarios profesionales.

## Características principales

- Diseño responsive adaptable a dispositivos móviles, tablets y computadoras.
- Sección principal tipo presentación (Hero).
- Información sobre la clínica.
- Servicios veterinarios.
- Galería de imágenes de mascotas.
- Favicon personalizado.
- Optimización básica para motores de búsqueda (SEO).
- Archivo robots.txt y sitemap.xml.
- Publicación mediante GitHub Pages.

##  Instalación y uso

Clonar el repositorio:

git clone https://github.com/kvvillalta/vetcare-cr.git


Ingresar a la carpeta del proyecto:

cd vetcare-cr


Abrir el archivo index.html en un navegador web para visualizar el sitio.
